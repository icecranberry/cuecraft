# 台球杆 AI 外观设计平台

依据 [plan.md](./plan.md) 落地的首版实现：以球杆实时三维预览为主体，直接选择部件、编辑材质、放置贴纸，并导出用于水贴／转印包覆的透明底 PNG。

## 运行

```bash
npm install
npm run dev        # 开发服务器（Windows 下若端口被保留，可加 --host 127.0.0.1 --port 3311）
npm run test       # Vitest 单元测试（映射 / 展开 / 抠图 / 规格校验，17 项）
npm run typecheck  # TypeScript 严格类型检查
npm run build      # 生产构建
```

要求 Node ≥ 18。所有数据（素材、设计、版本、作品）保存在浏览器 IndexedDB；API Key 仅保存在当前会话（sessionStorage，非持久化），不进入项目数据或导出文件。

设置中的图片生成 URL 是完整请求地址，直接使用用户填写的路径、尾斜杠和查询参数，不追加 `/v1`、`/images/generations`、`/images/edits` 或 `/models`。例如 Aikun 的生图示例填写 `https://aikun.uk/v1/images/generations`，模型填写 `gpt-image-2`。图片编辑 URL 与模型查询 URL 分别填写完整地址；参考图和多部位联动需要编辑 URL，缺失时在生图前提示。连接检测有模型查询 URL 时对该地址发 GET；否则只对图片生成 URL 发 HEAD，不生图，也不据此声称密钥、模型或出图能力已验证。

本地开发及 `npm run preview` 通过本地服务器转发 TokenRhythm 和 Aikun 请求，保留完整的上游路径与查询参数，以适配浏览器跨域限制。转发目标域名固定；密钥只随请求传递，不写入服务器文件或日志。其他供应商使用直连。部署到纯静态托管时，需要另行配置 `/api/image-provider/tokenrhythm` 和 `/api/image-provider/aikun` 转发。

完整地址以 `/chat/completions` 结尾时，生成请求使用服务商示例的 `model`、`messages`、`temperature` 格式，URL 保持原值。兼容聊天响应中的图片内容与 Markdown 图片；纯文字回答不会标记为生图成功。聊天接口的尺寸和质量由服务商决定，参考图仍需要单独的图片编辑 URL。设置页「单张试生成」使用当前输入的配置发送真实请求，成功图片保存到素材库。

## 多部位 AI 定制与聚焦距离

- AI 定制支持「多部位联动」和「单独调整部位」。提供前臂＋尾段、主纹样＋装饰环、后把通体三个组合，也可自行勾选部位。皮头不参与印刷；握把默认保留，可按通体设计需要选入。
- 参考用户提供的实物图，以及 [McDermott 工厂定制方案](https://www.mcdermottcue.com/mcdermott_custom_build_cue.php)：前臂与尾段采用呼应的主纹样，装饰环重复边框元素，握把可独立选择缠面或辅助图案。
- 每套联动候选先生成一张风格母稿，再通过图片编辑接口将同一母稿作为各部位参考，分别按用途、底材对比和展开尺寸构图。界面显示请求张数与进度；每张请求独立超时，可取消任务，已完成候选在后续失败时保留。兼容标准 `b64_json` 和服务扩展 `b64` 响应。
- 候选支持整套应用、仅应用某个部位、手动剪切、查看原始生成图。替换仅作用于候选记录的部位，锁定图层保留，也可关闭替换以叠加。按当前模型尺寸等比例放置，整套应用可一次撤销／重做；换杆型后不能将旧方案直接套入。生成与实际接口用量由用户点击触发。
- 小部件（皮头、先角、装饰环、端面、接头）聚焦的最近距离以 202mm 皮革握把的观察范围为基准；长部件继续按长度取景。接头／端面视角按钮采用相同下限，重复点击部件可重新聚焦。
- 自动化测试覆盖联动请求共用母稿、标准响应解析、单部位生成、失败保留候选、取消与超时、选择范围、等比例放置、撤销与聚焦距离。真实生成质量与实物试贴效果仍需在配置的图片服务及工厂样杆上核对。

## 已实现（对应 plan.md 章节）

### 首版业务闭环（§1.1）——全部贯通

选择杆型 → 查看原木／基础材质球杆 → 点击部件设置属性 → 上传／AI 生成图案 → 自动去白底／手动剪切 → 放置到杆身并调整 → 选择漆面 → 保存设计版本 → 检查展开版面 → 导出透明 PNG。

### 三维工作台（§3）

- 默认展示后把特写（约占画面宽度 2/3），可旋转／缩放（滚轮缩放、拖动空白处旋转），平移已禁用、球杆始终居中。
- 视角栏：整杆／前节／后把／接头／端面，重复点击会重新取景；双击三维部件或点击左侧「部件」列表项，动画聚焦该部件到画面中心。
- 选中反馈：部件显示琥珀色描边与名称牌；贴纸显示虚线框和浮动操控条（旋转 ±90°／放大缩小／复制／删除）。
- 右侧常驻属性面板：编辑状态以横幅区分——贴纸编辑（琥珀）、部件编辑（蓝）、球杆设置（中性）；内容按折叠分区组织。
- 左侧统一抽屉：部件／图层／素材三个页签；空状态直接提供「上传图案」「AI 生成」入口。
- 贴纸拖动优先于相机旋转；一次完整拖动记作一次撤销；贴纸位置绑定模型坐标（拖动到相邻旋转面自动换算）。
- Ctrl+Z／Ctrl+Y 撤销重做；Esc 取消放置状态；顶栏显示自动保存状态（已保存／保存中）。
- 帧率等开发信息仅开发模式显示。

### 杆型模板（§2）

- 仅保留大头杆：总长 1474mm，前支／后把各 737mm；中轮直径 21.4mm，大轮直径 31.4mm，先角直径 13mm。
- 皮头、先角／铜箍、前节、接头、装饰环、后把前臂、握把、后把尾段、端面分部件建模，真实毫米锥度，单元测试校验轴向连续与杆头／端面半径一致。
- 尺寸状态标注「用户指定尺寸」及来源说明；球杆模板页可查看完整规格表。模型按指定直径连续渐变，皮头厚度、先角长度及内部材质分段沿用展示值。

### 贴纸与映射（§4）

- Raycaster 拾取 → uv → 表面坐标（轴向 mm ＋ 环绕角 °）／端面局部 mm。
- 放置、拖动、毫米／角度精确输入、宽高锁定比、图案自身旋转（区别于绕杆角）、翻转、透明度、图层顺序、隐藏、锁定、复制、删除。
- 跨接缝双绘（环绕 0°/360° 连续）；跨段拖动保持轴向连续。
- 预览与导出共享同一贴纸描述与绘制规则；拖动时降采样纹理，停止后恢复清晰纹理。

### 底材与漆面（§5）

- 程序化双向无缝木纹（白蜡木／枫木／乌木／红木，细纹＋微扭曲）与皮革贴片＋法线贴图；金属（不锈钢／黄铜／黑金）与纯色预设；深色底材自动提高环境反射强度。
- MeshPhysicalMaterial 清漆层：亮光／半哑光／哑光，整杆应用或按部件覆盖；切换漆面不触发生图、不改变印刷内容。
- 摄影棚灯位（大面积柔光箱＋两条长条侧光形成柔和条形反射＋轮廓光），中性／明亮／深色背景；白模检查视图。

### GPTImage 与素材处理（§6／§10）

- 设置页：Base URL、API Key（会话级）、模型 ID（不写死）、尺寸、质量、超时；连接检测与试生成分离。
- 生成／基于参考图编辑（OpenAI 兼容 `/images/generations`、`/images/edits`）；主题／风格／配色／保留／避免＋白底固定要求。
- 任务状态机：排队／生成中／成功／失败／已取消／待核对（超时结果未知不盲目重试）；输入去重；任务记录持久化，刷新后标记待核对。
- 剪切编辑器：自动去白底（边缘连通识别＋容差＋保护画笔，白色主体与细线保留）、矩形／套索选区（保留／删除）、擦除／恢复画笔、羽化、边缘收缩、去白边、棋盘格等检查背景、按住看原图、撤销；蒙版非破坏。
- 素材库：上传、标签、搜索、放置到球杆、剪切、移除出库（被引用文件保留）。
- 有效清晰度 PPI 提示（§6.4，低于 150 PPI 提示过度放大）。

### 生产展开与导出（§7）

- 展开模板：旋转面按周长×轴长分块（锥度按半径差 ≤0.3mm 分段近似）、端面块；出血／搭接／镜像／行宽／PPI 可配置；块间毫米比例固定。
- 单张透明 PNG（px = mm ÷ 25.4 × PPI）：仅含印刷图层，不烘焙底材、漆面、灯光、阴影、辅助线；白色内容按原色保留；版面不自动裁切。
- 回贴检查：从导出 PNG 按块重载回贴到三维球杆，与编辑状态比对（实测位置一致）。
- 展开版面检查对话框（版面预览＋块清单）；产品效果图（带材质灯光的渲染截图）单独导出。
- 导出前自动保存版本快照；导出记录（尺寸／像素／块数／模板版本）留存。

### 保存与数据（§9）

- 自动保存（防抖 800ms）＋显式设计版本（不可变快照＋缩略图）；作品库归档、继续编辑、复制设计。
- 大图二进制存 IndexedDB，不进设计 JSON；版本恢复完整还原贴纸／蒙版引用／材质。

```

  state/                 Zustand 状态、历史、IndexedDB 持久化

  pages/                 工作台、素材库、球杆模板、作品库、设置

  tests/                 Vitest（映射/展开/命中/抠图/规格）
```

## 与计划的偏差（首版取舍）

| 项 | 计划 | 首版实现 | 原因 |
|---|---|---|---|
| 素材编辑 | Konva＋react-konva | Canvas 2D 直接实现 | 交互需求（选区／画笔／蒙版）用 Canvas 2D 完整覆盖，减少一层依赖 |
| 后端 | Fastify＋PostgreSQL＋Prisma＋Worker | 纯前端＋IndexedDB（接口语义预留） | 首版先验证核心闭环；数据契约（图层／模板／任务）已按 §8.2 模块边界组织，后端化时迁移 |
| API Key | 仅后端保管 | sessionStorage（会话级、非持久） | 无后端前提下的最近似方案；页面已注明后端化迁移路径 |
| 锥度展开 | 工厂校准模板 | 半径差分段近似 | §7.1 允许「分段近似」，待工厂样板校准 |
| 触屏 | 后续专门适配 | 桌面鼠标／键盘优先 | 与 §3.4 约定一致 |
